# LinkedIn Post Outline

Each of us writes our **own** post from this skeleton. Don't copy each other's wording. Credit each other by name.

## 1. Hook — the question (2–3 sentences)
> Amazon, Alphabet, Meta and Microsoft plan to spend about $[X]B on capital expenditures in 2026. In my Principles of Finance class we asked a simple capital-budgeting question: what would that spending have to earn to be worth it?

Tie to the case: a robotics firm's VP argued "$150M back on $100M invested — why not?" Totals aren't the test; NPV is.

## 2. What we built (3–4 sentences)
- AI tool used: Claude — be specific about what we asked it to do (pull capex guidance from four earnings releases, build a break-even calculator, chart scenarios).
- One iteration: what the first attempt got wrong and what we changed.

## 3. The result (visual + 2–3 sentences)
- Hero chart (Concept B or C from [[06 Deliverable Concepts]]).
- One sentence with the key number: "At a 10% required return and a 6-year server life, 2026's spending alone needs about $[CF]B of after-tax cash flow every year through 2032."
- Link to the tool page.

## 4. Where AI got it wrong (2–3 sentences)
- Pick one from [[07 AI Error Log]]. Say how we verified it (primary source, hand calculation).

## 5. What's next (1–2 sentences)
- e.g., add Meta's ad revenue, model GPU obsolescence at 3–4 years, rerun when Q4 guidance comes out.
